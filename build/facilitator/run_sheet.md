# Run sheet — facilitator only

Total active time: 75 minutes, plus debrief. Setting: the Academy. Station word: fridge.

Server: `https://your-deployment.example/mcp`. No logins. Records unlock through passcodes that teams send with every tool call.

| Minute | Activity | Facilitator action |
| --- | --- | --- |
| Before | Preflight | Check one successful MCP call per team. Prepare the two release-code cards (`props/release-codes.md`) |
| 0–15 | Wiki building | Give the starter and read the search boundary; don't give the case yet |
| 15 | Case drops | **Announce `DEMO-PHASE-ONE`** (say it and show the card). Read the opening question. Teams get the checklist with `case_get_brief` |
| 15–35 | Investigation | Walk around; early room search is allowed |
| 30 | Card-log hint if needed | “The ghost was thirsty that night.” |
| 35 | Wednesday release | **Announce `DEMO-PHASE-TWO`**: “IT has recovered the audit history and the shared drive.” |
| 35–50 | Room and revision | Use the decryption hints from minute 40 |
| 45 | Marketing-theory hint | Give the quoted-reply hint if the team is still stuck on Jule |
| 50 | Shift change | Fresh AI conversation from the saved wiki, including room photos and passcodes |
| 50+ | Costume-link hint | Give the expense hint only if that link is missing |
| 60 | CEO-theory hint | Give the distance/call-time hint if needed |
| 60–75 | Answers on paper | Mark each sheet solved or “Not convinced. Attempts left: N.” Note the time |
| End | Reveal | **Announce `DEMO-FINALE`.** Every team can now see everything, card log and vault included |
| 75+ | Debrief | Compare first and final answers; reveal the timeline and one-liners |

## Search boundary to read at minute 0

Some clues are hidden around this room and in the bathrooms. Finding them never requires opening, unplugging or moving equipment, and nothing is hidden in the real server room, desks, bins, offices or stairwells. Photograph what you find; don’t take it.

The server keeps no progress. Ask teams how far they are before giving a hint. A team that hasn't decrypted by the shift change can still finish: codes work in any conversation. Put duplicate labels in all permitted bathrooms.
